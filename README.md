# ac-subglacial-lakes 

The repository contains most of the supplemental material (including documentation, workflows, figures, and code, but excluding the derived data) presented in the article "Active subglacial lakes in the Canadian Arctic identified by multi-annual ice elevation changes," which has been submitted for review.
